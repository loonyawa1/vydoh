# Выдох

Учебный лонгрид: как менялось общество от повседневного курения 1940-х до закона 2013–2014 годов и сегодняшнего дня.
Это исторический материал, а не реклама. **Курение вредит вашему здоровью.**

Сайт: https://loonyawa1.github.io/vydoh/

Обычная статическая страница без сборки: `index.html`, `assets/css`, `assets/js`.
Авторы и лицензии всех снимков и видео перечислены в конце страницы. Шрифты распространяются по SIL Open Font License, тексты лицензий лежат в `assets/fonts/licenses`.
